## Откат хостов на Go (2026-10-07, вечер) + задача допилки C

Оба хоста откачены на ssh3-go 0.1.26 (deb из GitHub-релизов; postinst сохранил имевшиеся сертификаты — пины known_hosts целы, транспорт проверен mcp'ом: WSL-GO-RESTORED / MF-GO-RESTORED; mf снова dual-stack *:443). Наш пакет удалён с обоих.

**Причина отката** (дивергенции Go vs C, вскрытые живой эксплуатацией): (1) C-сервер не делает per-session setuid — сессии идут от юзера демона (hardened-юнит к тому же резал sudo через NoNewPrivileges; снято дроп-ином, но это костыль), Go-сервер — root-демон с setuid как OpenSSH; (2) IPv4-only бинд против dual-stack; (3) version-заголовок C-сервера не парсится Go-клиентом («bad SSH version fields»); (4) -K один файл против двух авториз-файлов форка + systemd съедает %u в ExecStart; (5) -url-path/-gateway-ports/password-opt-in флагов нет.

**Задача допилки C до нормального функционала (P7.3, до миграции инфры):** per-session setuid (root-демон или CAP_SETUID/CHOWN/DAC_READ_SEARCH у ssh3-юзера; host-keys root:600; setuid/initgroups в session_srv; юниты обратно root-демон — socket-активация сохраняет беспарольный 443), dual-stack бинд, version-заголовок по формату Go-клиента, -K с двумя авториз-файлами (+%%u в юнитах), -url-path/-gateway-ports. Критерий: sudo из сессии, второй юзер, матрица 25/25, полный цикл миграции обоих хостов повторно.
