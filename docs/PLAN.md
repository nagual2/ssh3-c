Создан: 2026-10-01. Источники: [ARCHITECTURE.md](ARCHITECTURE.md) (слои, решения, zero-copy правила), [DEPS-QUIC.md](DEPS-QUIC.md) (зависимости, лицензии). Родительский трек: `project/ssh3/docs/ROADMAP.md`.

## 1. Целевая позиция: «OpenSSH среди Linux-систем»

Цель проекта: ssh3-c со временем занимает в Linux-системах место, аналогичное OpenSSH, с соответствующей лицензией. Что это означает в конкретных признаках:

| № | Признак OpenSSH | Цель ssh3-c | Статус |
|---|-----------------|-------------|--------|
| 1 | Язык — чистый C | C17 | решено (2026-10-01) |
| 2 | Лицензия — пермиссивная (OpenBSD/ISC-семейство, без copyleft) | собственный код — BSD-2; заимствованный nginx-код — BSD-2 (совместимо); `THIRD-PARTY-NOTICES.md` | решено |
| 3 | Зависимости — только системные (libcrypto, zlib) | только `libcrypto` (OpenSSL ≥3.5 QUIC API) | решено (DEPS-QUIC.md) |
| 4 | Протокольный слой — собственный код проекта | QUIC+H3 — наш исходник (адаптация nginx) | решено |
| 5 | Пакеты в дистрибутивах, man-страницы, systemd-юниты | deb/rpm/apk/ipk, man, socket-активация | фаза P7 |
| 6 | Сосуществование с предшественниками (OpenSSH заменил telnet/rsh, а не стёр их) | ssh3 — отдельный пакет рядом с OpenSSH, не замена | фаза P7–P8 |
| 7 | Качество, приемлемое для security-команд дистрибутивов | fuzzing, sanitizers, аудит (R2), интероп-матрица | фазы P6+ |

Спека протокола — `SSH 3.0 alpha-00` (первоисточник — Go-реализация francoismichel/ssh3, форк nagual2 унаследовал протокол). IETF-трек закрыт (2026-10-16, решение владельца): апстрим мёртв, draft-michel-remote-terminal-http3-00 истёк — спека становится документом проекта (rev nagual2/1, этап (0) P8 в §4).

## 2. Язык и лицензия (фиксация решений)

- **C17** (заменило прежнее «C++20»): оба референса (OpenSSH, nginx) — C; libstdc++ отсутствует в базовых системах (Alpine base, embedded/OpenWrt); C-ABI стабилен. Полиморфизм — указатели на функции (паттерн `ngx_connection_t`), не классы.
- **Windows-клиент (P9) — тоже C17** (подтверждено Пилотом 2026-10-10): переносимый код уже C17 с покрытием (ctest/fuzz/интероп), новый — только os-слой и CLI-каркас; C++ отвергнут повторно — аргумент libstdc++ для Windows неприменим, но встречного нет: все системные интерфейсы (WinSock, ConPTY, named pipes) суть C API. Модель порта — по образцу `src/os/win32/` nginx 1.31.7 (6 147 строк чистого C): платформенное целиком в `src/os/win/` (зеркало `os/unix/`), `s3_errno.h` с `S3_E*`→Win-кодами (`S3_EAGAIN=WSAEWOULDBLOCK`), I/O-таблица на указателях функций (WSARecv/WSASend поверх `s3_chain_t`, WSABUF≡iovec, склейка смежных), сигналы → named events + поток-ждатель, таймер-кап 500 мс; event-бэкенд — select/WSAPoll первым (клиенту хватает, FD_SETSIZE=64 неважен), IOCP за флагом; сокеты сразу `WSA_FLAG_OVERLAPPED`; сборка clang-cl/mingw + OpenSSL 3.5 из vcpkg (DEPS-QUIC.md §7.3). Скилл — `c-win32`.
- **Лицензия**: весь новый код — BSD 2-clause (копирайт владельца проекта); адаптированные файлы nginx сохраняют `Copyright (C) Nginx, Inc.` + наша строка; в корень репо — `LICENSE` + `THIRD-PARTY-NOTICES.md`. Это функционально тот же класс пермиссивности, что у OpenSSH (OpenBSD-лицензия ≈ ISC ≈ BSD-2).
- Каталог переименован `project/ssh3-cpp` → `project/ssh3-c` (cpp в имени более не соответствует языку).

## 3. Треки: общий каркас, сервер, клиент

Слои `core/event/os/quic/h3` — общие и симметричные для клиента и сервера. Разветвление начинается на слое `ssh3/`:

| № | Слой | Сервер | Клиент |
|---|------|--------|--------|
| 1 | Общий (P0–P3) | core/event/os/quic/h3 — один код, два бинарника | тот же |
| 2 | `ssh3/` + `app/` | accept-лупы, auth-верификаторы (`authorized_identities`, `getpwnam`/shadow, JWT/Basic), exec/shell/PTY (termios), sftp-подсистема с jail, forward-обработка, agent UDS, login banner | dial+0-RTT, known_hosts TOFU, auth-провайдеры (password/JWT-файл/JWT-агент), session pump (stdin/stdout/PTY raw+resize), forward-инициаторы, ControlMaster, sftp-клиент с resume |

Сборка: два бинарника `ssh3` и `ssh3-server` из одной кодовой базы (аналог `cmd/ssh3`, `cmd/ssh3-server` в Go).

| № | Пункт | Решение |

| 1 | Runtime-проба `EXPORTER-SSH3` (§13.1) — единственная неисполненная проба пасса | **Исполнена**: байты экспортера двух сторон совпадают, негативный контроль (другая метка) расходится — `tests/test_quic_e2e.c`, случай `s3_test_quic_e2e_exporter` |
| 2 | I3-5 `disable_active_migration` не enforced | **Оставлено как в референсе** (nginx тоже не enforce'ит) и задокументировано в коде: флаг парсится и эмитится, ни одна конфигурация его не объявляет, enforcement не делается |
| 3 | §11.5: нереентерабельный `static`-буфер GSO | **Задокументировано** в коде: ограничение однопоточного event loop, форма референса |
